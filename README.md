📚 Study Planner Web Application

📌 Project Description

The Study Planner Web Application is a simple, responsive website designed to help students organize their academic activities. It allows students to add study tasks, set assignment deadlines, track completed and pending tasks, and manage their daily study activities in one place.

This project was developed as part of my learning journey in front-end web development, with the aim of applying my knowledge of HTML, CSS, and JavaScript to build a practical and user-friendly website.

✨ Features

Add Tasks: Add assignments and study activities to your task list.
Set Deadlines: Assign due dates to tasks to help manage deadlines.
Track Tasks: View the total number of tasks, completed tasks, and pending tasks.
Mark Tasks as Completed: Check off tasks when they are completed.
Delete Tasks: Remove tasks that are no longer needed.
Responsive Design: Access the website on different screen sizes, including mobile phones and computers.
Simple Interface: Enjoy a clean and easy-to-use layout.
🛠️ Technologies Used

HTML5: Used to structure the website.
CSS3: Used to style the website and create a responsive layout with Flexbox and CSS Grid.
JavaScript: Used to implement interactive features, manage tasks, and update task statistics.
🚀 How to Run the Project

Follow these steps to run the project on your computer:

Clone or download this repository from GitHub.
Extract the downloaded folder if necessary.
Open the project folder.
Locate the "index.html" file.
Open "index.html" in your web browser.
Start adding and managing your study tasks.
Alternatively, you can open the project in Visual Studio Code and use the Live Server extension to preview the website.

🎯 Project Objective

The objective of this project is to apply fundamental front-end development skills to solve a practical problem faced by students: organizing academic tasks and keeping track of assignments and deadlines.

It also serves as a learning project for practising HTML, CSS, responsive web design, and JavaScript.
